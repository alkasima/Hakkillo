Hakkillo / browser demo

Small enough to run right here.

Load the model once, then chat on this device. The download is about 170 MB and may be cached by your browser.

Your messages are processed in this browser. Model files are downloaded from Hugging Face; app libraries come from jsDelivr. No API key is needed.

Ready when you are.
An experiment, with honest limits. This first release can misunderstand requests, invent facts, and give incorrect answers. It has no live web access. Start with short English questions and check important information.
Built on SmolLM2 by Hugging Face.
