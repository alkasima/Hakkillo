Hakkillo / browser demo

Small enough to run right here.

Load the model once, then chat on this device. The download is about 141 MB and may be cached by your browser.

Your messages are processed in this browser. Model files are downloaded from Hugging Face; app libraries come from jsDelivr. No API key is needed.

Ready when you are.

Try a starter prompt after loading. Each one starts a fresh conversation so results are easier to compare.

For the challenge, look for a polite rewrite. v0.1 may instead say it cannot access files. That mistake is useful feedback.

Found something confusing? Copy the last prompt and reply, review the text, then paste it into a GitHub issue. The copy includes the model version and any earlier turns used for that reply. Nothing is submitted automatically.

An experiment, with honest limits. This first release can misunderstand requests, invent facts, and give incorrect answers. It has no live web access. Start with short English questions and check important information.
Built on SmolLM2 by Hugging Face.
